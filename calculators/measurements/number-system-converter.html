Number System Conversion Guide

Different number systems are used in computing, electronics, and mathematics. Computers use binary (base-2) internally. Programmers often use hexadecimal (base-16) for memory addresses and color codes. Octal (base-8) was once common in Unix systems. Understanding conversion between these systems is a fundamental programming skill.

Binary (Base-2)

Binary uses only 0 and 1. Each position represents a power of 2: 1, 2, 4, 8, 16, 32, 64, 128... Binary 1010 = 1x8 + 0x4 + 1x2 + 0x1 = 10 decimal. All computer data is ultimately stored as binary bits. 8 bits = 1 byte. 1 KB = 1,024 bytes = 8,192 bits.

Hexadecimal (Base-16)

Hex uses 0-9 and A-F (A=10, B=11, C=12, D=13, E=14, F=15). Each hex digit = 4 binary bits (a nibble). Used for HTML colors (#FF5733), memory addresses (0x1A2B), and machine code. FF hex = 255 decimal = 11111111 binary.

Octal (Base-8)

Octal uses digits 0-7. Each octal digit = 3 binary bits. Unix file permissions use octal: chmod 755 = binary 111 101 101 = rwxr-xr-x. Less common today but still used in Linux/Unix systems.

Frequently Asked Questions

How do you convert decimal to binary? +
Repeatedly divide by 2 and record remainders from bottom to top. Example: 13 / 2 = 6 R1, 6/2=3 R0, 3/2=1 R1, 1/2=0 R1. Reading remainders bottom to top: 13 = 1101 binary.
How do you convert hex to decimal? +
Multiply each hex digit by its power of 16 and sum. Example: 1F hex = (1x16) + (15x1) = 16 + 15 = 31 decimal. A = 10, B = 11, C = 12, D = 13, E = 14, F = 15.
What is FF in decimal? +
FF hex = 255 decimal = 11111111 binary. This is the maximum value of 1 byte (8 bits). Used in networking (255.255.255.0 subnet mask), HTML colors (#FFFFFF = white), and many other computing contexts.
What does 0x mean before a number? +
0x is a prefix in programming languages (C, C++, Java, Python) indicating the number is hexadecimal. 0x1A = 26 decimal. 0xFF = 255 decimal. Similarly, 0b prefix indicates binary: 0b1010 = 10 decimal.
How are HTML colors in hexadecimal? +
HTML colors use 6 hex digits: #RRGGBB where RR, GG, BB are red, green, blue values from 00 (0) to FF (255). #FF0000 = red, #00FF00 = green, #0000FF = blue, #FFFFFF = white, #000000 = black.
What are Unix file permissions in octal? +
Unix permissions: r (read=4), w (write=2), x (execute=1). chmod 755 = 7 (rwx for owner) + 5 (r-x for group) + 5 (r-x for others). chmod 644 = 6 (rw- owner) + 4 (r-- group) + 4 (r-- others).
