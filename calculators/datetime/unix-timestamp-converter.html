What is a Unix Timestamp?

A Unix timestamp is the number of seconds elapsed since the Unix Epoch — January 1, 1970 at 00:00:00 UTC. It is a single integer that uniquely identifies any moment in time, used universally in programming, databases, and APIs.

Unix Time = Seconds since January 1, 1970 00:00:00 UTC

For example: timestamp 1700000000 = November 14, 2023 at 22:13:20 UTC.

Why Developers Use Unix Timestamps

  • Language-agnostic: Works identically in Python, JavaScript, PHP, Java, C++
  • Time zone safe: Always in UTC — no ambiguity about local time zones
  • Easy arithmetic: Adding 86400 seconds = exactly 1 day later
  • Database efficient: Stored as a single integer, faster than string date fields
  • Sorting: Timestamps sort chronologically as simple integers

What is the Unix epoch? +
The Unix epoch is January 1, 1970, 00:00:00 UTC — the zero point for all Unix timestamps. The choice was made in the early 1970s when Unix was developed at Bell Labs.
What is the Year 2038 problem? +
32-bit systems store timestamps as signed 32-bit integers, maxing at 2,147,483,647 (Jan 19, 2038). After this, the value overflows to a negative number, causing date errors. Modern 64-bit systems are not affected.
What is the difference between Unix time and milliseconds? +
Unix time is in seconds. JavaScript's Date.now() returns milliseconds — divide by 1000 to get Unix seconds. APIs may use either format, so always check the documentation.
How do I get the current Unix timestamp in Python? +
Use: import time; print(int(time.time())). In JavaScript: Math.floor(Date.now()/1000). In PHP: time(). In Linux terminal: date +%s.
