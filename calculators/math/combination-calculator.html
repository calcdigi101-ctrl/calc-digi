Combination Calculator (nCr)

Calculate combinations — the number of ways to choose r items from n items where order doesn't matter. Used in lottery odds, card games, team selection, and statistics.

Combination Formula

nCr = n! / (r! × (n − r)!)

This counts unordered selections. Choosing a 3-person committee from 10 people: 10C3 = 120 possible committees (since the order of selection doesn't matter).

Real-World Examples

  • Lottery (6/49): C(49,6) = 13,983,816 possible combinations
  • Poker hand (5 cards from 52): C(52,5) = 2,598,960 hands
  • Committee of 3 from 10 people: C(10,3) = 120 committees
  • Pizza with 3 toppings from 8: C(8,3) = 56 combinations

How do lottery odds use combinations? +
Since lottery numbers are drawn without regard to order, combinations apply. A 6/49 lottery has C(49,6) ≈ 14 million possible combinations, making any single ticket's odds very low.
Is nCr always smaller than nPr? +
Yes. nCr = nPr / r!, since each combination produces r! different permutations that combinations group together. Combinations are always equal to or fewer than permutations.
What is Pascal's Triangle? +
Pascal's Triangle is a triangular array where each entry equals nCr. Row n lists all combinations from nC0 to nCn. Each value is the sum of the two values above it in the triangle.
What does nC0 equal? +
nC0 = 1 for any n. There is exactly one way to choose zero items from a set — choose nothing. Similarly, nCn = 1 (choose everything).
