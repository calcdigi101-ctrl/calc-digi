Key Matrix Operations

Determinant: |A| = ad − bc, for matrix [[a,b],[c,d]]
Multiplication: C[i][j] = Σ A[i][k] × B[k][j]

Matrix addition and subtraction combine corresponding elements. Matrix multiplication uses the row-by-column dot product — the result at position (i,j) is the dot product of row i from A and column j from B.

What is a matrix determinant used for? +
Determinants determine if a matrix is invertible (nonzero det), calculate areas and volumes in geometry, and are essential in solving systems of linear equations using Cramer's rule.
Is matrix multiplication commutative? +
No — A×B ≠ B×A in general. Matrix multiplication is non-commutative, which is one key way it differs from regular number multiplication.
What does a zero determinant mean? +
A zero determinant means the matrix is singular — it has no inverse. The rows/columns are linearly dependent and the system of equations it represents has no unique solution.
What is the identity matrix? +
The identity matrix I has 1s on the diagonal and 0s elsewhere: [[1,0],[0,1]]. Multiplying any matrix by I returns the original matrix unchanged — analogous to multiplying a number by 1.
