Absolute Value Calculator

Calculate the absolute value of any number instantly — the distance from zero on the number line, always non-negative. Also find the distance between two values.

Absolute Value Definition

|x| = x if x ≥ 0; |x| = −x if x < 0

Absolute value strips the sign, always returning a non-negative result. Both |−7| = 7 and |7| = 7. The notation |x| represents the distance from x to 0 on the number line.

Real-World Uses of Absolute Value

  • Temperature deviation: How far from target temp, regardless of above/below
  • Financial errors: Measuring variance without caring if it's over or under
  • Engineering tolerance: Part can be ±0.5mm from spec — absolute error must be ≤ 0.5
  • Distance on number line: Distance between points a and b = |a − b|

What is absolute value used for? +
It measures magnitude without direction — used in error measurement, distance, deviation from target, and any situation where you only care about "how much" not "which way."
Can absolute value be negative? +
No, absolute value is always ≥ 0. It represents distance, which cannot be negative.
What is |0|? +
|0| = 0. Zero is exactly 0 units from itself on the number line.
How do you solve absolute value equations? +
|x| = 5 has two solutions: x = 5 and x = −5, since both are distance 5 from zero. In general, |x| = a gives x = a or x = −a (when a ≥ 0).
